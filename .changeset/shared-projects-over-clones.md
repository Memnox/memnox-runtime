A repository the organization shares in Memnox Cloud now reaches the clone whose `origin` reduces to it, by the same `host/owner/name` rule the cloud uses. The `projects` view marks that clone `scope: 'organization'` and shows what it hands: its servers and skills looked up in the bundle, how many published rules carry its rule pack, and every name the bundle did not carry, said and skipped. What an agent learns there is kept on the shared project's id, apart from the person's own memory, or not at all where the project keeps none, and writing the project's manifest here is refused with the Memnox Cloud line.
