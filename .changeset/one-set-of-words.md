The terminal card answers a held call with the same words, in the same order, as the console, the Mac app and the phone: Allow once, Allow for this session, Edit the command first, Deny. A decided call reads "denied" rather than "refused". Session statuses and their reasons have one vocabulary, kept in `docs/ux/contract.json`, which every surface checks itself against.
