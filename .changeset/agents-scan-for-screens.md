A new daemon method, `agents-scan`, answers in `agentsScan` the agents the scan finds now with the counted facts the voice's full screen scan draws: each MCP server by name with the program it starts and its tools from the tool list cache, `working` for sessions working now and `open` apart, over the last 24 hours, and each agent's share of the real capabilities. A server never asked is counted behind the answer, so `total` stays absent while counting and is never a false zero. Only the Mac may ask it, since it can start servers to count them. Each `AgentServer` on the scan screen now carries `command`, the program by file name only.
