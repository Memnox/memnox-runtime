A new daemon method, `workspace-memory`, answers what the workspace settled and what its connected tools said as this machine last pulled it, read off disk with no network near it, so the Mac app draws the workspace's memory beside its own. It is read under SEE from a phone, and it is only a read down: nothing local goes up with it.
