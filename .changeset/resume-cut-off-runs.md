A run that a crash, a reboot or a closed laptop cut off now shows in `memnox sessions` as Stopped, Interrupted, resumable. `memnox resume <session>` asks first and then starts it again in the same folder, with the same task, role, person and mission. Claude Code and Codex pick their own conversation back up; any other agent starts fresh, and the screen says so.
